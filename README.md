# HCC serum N-glycomics report

Standalone Traditional Chinese report for the Guangzhou discovery cohort (Fu et al., Nature Communications, 2026; https://doi.org/10.1038/s41467-026-68579-x).

The page is bilingual. It continues the raw-data tutorial and includes a group-wise schematic MALDI spectrum with SNFG cartoons on the differential peaks, then PCA, a biplot, a volcano plot, a clustered heatmap, Spearman correlation with clinical values, box plots, and a logistic-regression ROC. Each figure is followed by the R fragment that produces it. Figures and structures are embedded in `index.html`.

https://hunglinchen2003.github.io/hcc-glycomics-report/

Related pages:

- Tutorial: https://hunglinchen2003.github.io/hcc-glycomics-tutorial/
- Structure database: https://github.com/hunglinchen2003/glycan-structure-db

This repository does not include the raw spectra.
